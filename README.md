Project Overview

The Enterprise Hotel Management System (HMS) is a console-based Java application designed using enterprise-level layered architecture principles. The system simulates real-world hotel operations including customer registration, room management, booking workflows, payment processing, and reporting.

The project is built using:

Java 17+
Hibernate 6.x / JPA 3.x
MySQL 8.x
Maven
Layered Monolith Architecture

This project demonstrates:

Object-Oriented Programming
Hibernate ORM
Layered Architecture
Repository Pattern
Generic Programming
Java Streams API
Concurrency & Multithreading
Exception Handling
Collections Framework
DTO Design using Java Records
